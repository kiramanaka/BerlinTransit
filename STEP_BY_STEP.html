Step 4: Build APK

1
Go to Actions
Tap Actions tab at the top of your repository
2
Select Workflow
Tap Build APK from the list
3
Run Workflow
Tap Run workflow (dropdown on right)
Select branch: main or master
Tap Run workflow button
4
Wait for Build
⏱️ Takes 3-5 minutes
Yellow dot = Running
✅ Green check = Success
❌ Red X = Failed (check logs)
💡 The build runs on GitHub's servers (x86-64), so it works perfectly!

Step 5: Download & Install

1
Download APK
Tap the green checkmark (successful build)
Scroll to Artifacts section
Tap berlin-transit-debug
2
Install on Xiaomi 17T
Open File Manager → Downloads
Tap app-debug.apk
When prompted: Settings → Enable Allow from this source
Go back → Tap Install
3
First Launch
Tap Open
Grant location permission
View real-time departures! 🎉
4
Add Widget
Long-press empty home screen area
Tap Widgets
Find Berlin Transit Widget
Drag to home screen
