🚇 Berlin Transit

Build this app on your phone in 5 minutes!

📦 Download Project

1
Download the project files to your phone

The project is at: /workspace/BerlinTransit.tar.gz

Copy this file to your phone's Downloads folder.

🔧 Build via GitHub (Recommended)

1
Go to github.com and sign up (free)
2
Create a new repository named BerlinTransit
3
Tap Add file → Upload files
4
Upload ALL files from the BerlinTransit folder
5
Tap Commit changes
6
Go to Actions tab → Select Build APK
7
Tap Run workflow → Wait 3-5 minutes
8
Download the APK from Artifacts section

📱 Install on Xiaomi 17T

1
Open File Manager → Find downloaded APK
2
Tap to install (enable "Install unknown apps" if prompted)
3
Open app → Grant location permission
4
Add widget: Long-press home → Widgets → Berlin Transit

⚠️ Important Files to Upload

  • app/src/main/ (all files)
  • app/build.gradle.kts
  • build.gradle.kts
  • settings.gradle.kts
  • gradle.properties
  • gradlew and gradlew.bat
  • gradle/wrapper/ (entire folder)
  • .github/workflows/build.yml
  • local.properties
